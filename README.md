# Flipkart Returns Intelligence Dashboard

An end-to-end Advanced Excel analytics project focused on understanding how product returns impact e-commerce operations. This project analyzes 34,500 Flipkart-style orders to uncover patterns in returns, refunds, delivery performance, customer behavior, and profitability through an interactive dashboard.

## Story Behind This Project

Instead of creating another sales dashboard, I wanted to solve a real operational problem faced by e-commerce companies—why are customers returning products, and what is the business impact of those returns? I approached this project from an Operations Manager's perspective, using data to identify high-return categories, refund costs, delivery inefficiencies, and customer trends that could support better business decisions.

## What I Did

* Cleaned and transformed raw data using Power Query by validating data types, removing duplicates, and creating business-ready fields.

* Built interactive dashboards using Pivot Tables, Pivot Charts, and Slicers to analyze returns across categories, regions, payment methods, customer segments, and discount bands.

* Developed executive KPIs including Return Rate (5.52%), Total Refund Amount (₹388,756), Total Revenue (₹5.87M), Average Delivery Days (4.81), and Average Profit Margin (28.12).

## Key Insights

* Fashion recorded the highest return rate (8.28%), followed by Electronics (7.30%).

* Grocery had the lowest return rate (1.31%).

* Regional delivery performance and refund trends highlighted opportunities for operational improvement.

## Tools Used

Advanced Excel, Power Query, Pivot Tables, Pivot Charts, Slicers, KPI Reporting, and Business Analysis.
